# 📝 To-Do List Application

A simple and user-friendly **To-Do List web application** developed using *FastAPI, HTML, CSS, and JavaScript**.

The application allows users to create, manage, update, and delete their daily tasks.

## 🚀 Features

* User Login
* User Logout
* Add New Todo
* Add Todo Title
* Add Todo Description
* View Todo List
* Mark Todo as Completed
* Edit Todo
* Delete Todo
* Pending and Completed Status
* Simple and user-friendly interface

## 🛠️ Technologies Used

### Backend

* Python
* FastAPI
* SQLAlchemy
* Pydantic

### Frontend

* HTML
* CSS
* JavaScript

### Database

* Database integration using Python and SQLAlchemy

## ▶️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/devika05perumal/todo-list-fastapi.git
```

### 2. Open the project folder

```bash
cd todo-list-fastapi
```

### 3. Create and activate virtual environment

```bash
python -m venv todolist
```

Windows:

```bash
todolist\Scripts\activate
```

### 4. Install required packages

```bash
pip install -r requirements.txt
```

### 5. Run the FastAPI application

```bash
uvicorn main:app --reload
```

### 6. Open the application

Open your browser and visit:

```text
http://127.0.0.1:8000
```
